https://github.com/gilbertorodriguez59/libro-machine-learning-teorico

## Renderizar

Para generar la versión HTML en la carpeta `docs`:

```bash
quarto render --to html
```

Para previsualizar:

```bash
quarto preview
```

Para generar el PDF:

```bash
quarto render --to pdf
```

## Publicación

GitHub Pages debe configurarse con:

- Branch: `main`
- Folder: `/docs`
